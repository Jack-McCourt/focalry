## Multi-tenancy

**Every resource is scoped to a `Studio` (tenant).**

- `Studio` = the photographer's account (Cashier billable entity).
- `User` = a person who belongs to a Studio (owner/admin/member).
- All studio-scoped models use the `BelongsToStudio` trait (`app/Models/Concerns/BelongsToStudio.php`).
- The `SetCurrentStudio` middleware (`app/Http/Middleware/SetCurrentStudio.php`) sets `app('current.studio.id')` from the authenticated user on every request.
- **Never trust client input for tenant scope.** Always resolve studio from the authenticated user.

## Storage layout (Wasabi)

```
studios/{studioId}/collections/{collectionId}/originals/{uuid}.ext
studios/{studioId}/collections/{collectionId}/photos/{photoId}/{thumb|web|preview|print}.ext
```

- Originals uploaded via presigned URLs (browser → Wasabi directly).
- Derivatives generated by queued jobs, never in the request lifecycle.
- All client-visible URLs are short-lived signed URLs from Wasabi/CDN.

## Key patterns

### Presigned uploads
`POST /api/uploads/presign` → returns `{ url, key }` → browser uploads directly to Wasabi.

### Commission rate
- Free plan: 15% platform commission via Stripe Connect `application_fee_amount`.
- Paid plans: 0% commission.
- See `Studio::effectiveCommissionRate()`.

### Money
Store all amounts as **integer minor units** (cents). Stripe is source of truth.
Never mark orders/invoices paid from the client side — always from Stripe webhooks.

### Webhook handling
Stripe webhooks → `POST /api/stripe/webhook` → `App\Http\Controllers\Stripe\WebhookController` (extends Cashier's webhook controller).
Webhook signature is verified by Cashier middleware. Handlers must be idempotent.
